# 健康資料管理系統 (Local Health Data Management System)

一套專為校園、活動或團體設計的**輕量級定期健康數據追蹤系統**。系統架構採用 Python 後端結合原生 HTML/CSS/JavaScript 前端，具備 100% 本地端離線儲存、零個資外洩風險，並可打包為單一獨立桌面軟體（.exe）。

---

## 🌟 核心特色

1. **絕對離線與個資安全 (Air-Gapped & Privacy-First)**
   - 全系統不依賴任何外部雲端 API 或資料庫。
   - 前端不引入任何第三方遠端 CDN、字型或追蹤腳本，杜絕任何潛在 IP/個資傳輸。
   - 多人接續使用時具備自動重刷機制（Auto-Reset），送出後立即銷毀暫存，防止下一位使用者窺探前人數據。

2. **精準 Excel 儲存與原生公式**
   - 資料自動依月份分頁（Worksheet）歸檔管理。
   - 包含自動計算 BMI 原生 Excel 公式（`=IFERROR(ROUND(...), 1)`），支援即時連動。
   - 週次自動時間軸排序：即使歷史補登資料，亦會自動由小到大（第1週 $\to$ 第2週...）排列。

3. **直覺友善的填報介面**
   - **身分欄位獨立分開**：姓名、學號、暱稱、活動編號各自獨立。
   - **擇二自動補齊**：初次填報完整建立；之後每週僅需「名字/暱稱擇一」＋「學號/活動編號擇一」，系統自動比對補齊其餘欄位。
   - **模擬市售血壓機排版**：上格收縮壓（高壓）、下格舒張壓（低壓），避免同學混淆專有名詞。
   - **防呆確認機制**：初次建立名單送出前跳出二次核對，並提示姓名與學號一旦鎖定不得隨意更改。

4. **時效過期鎖定與隱密管理員特權**
   - 一般使用者僅能檢視與修改當週數據；過期週次與歷史月份自動鎖定為唯讀。
   - 內建 1 分鐘短效管理員特權模式（可在獨立的 `admin_config.txt` 自訂帳密），特權模式下開放指定月份/週次補登與歷史修正。

5. **原生桌面軟體體驗 (pywebview)**
   - 封裝為原生桌面軟體，關閉視窗時立即徹底釋放連線 Port，不殘留背景處理程序。
